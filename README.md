# Simple Calculator Web App

This is a simple web-based calculator application built with Python and Streamlit. It allows users to perform basic arithmetic operations like addition and subtraction.

## How to Download and Run

To run this web application on your local machine, please follow these steps:

1. **Download the code:** 
   Click the green **Code** button at the top of this repository and select **Download ZIP**, or clone the repository using Git:
   `git clone https://github.com/shadabmarwat00-collab/se-assignment-01.git`

2. **Install Python dependencies:**
   Open a terminal in the downloaded folder and install the required libraries:
   `pip install -r requirements.txt`

3. **Run the application:**
   Start the web server by running the following command:
   `streamlit run app.py`

4. **View the app:**
   A browser window will open automatically, or you can go to `http://localhost:8501` to use the calculator.
